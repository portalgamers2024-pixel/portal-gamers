¿QUÉ CAMBIA?
================================================================================

ESTRUCTURA ACTUAL (Problema):
  ├─ Tasas fijas en cada moneda
  ├─ Difícil actualizar múltiples monedas
  ├─ Riesgo de inconsistencias
  └─ No hay relación clara: USD → otras monedas

ESTRUCTURA NUEVA (Solución):
  ├─ USD como base única
  ├─ Tasas centralizadas en fila 5
  ├─ Cambios automáticos en todas las monedas
  ├─ Fácil de mantener y auditar
  └─ Transparencia: USD * Tasa = Moneda Local

PASO A PASO: CÓMO IMPLEMENTAR
================================================================================

PASO 1: RESPALDAR Google Sheet
───────────────────────────────────────────────────────────────────────────
1. Abre Google Sheet
2. Menú: Archivo → Descargar → Microsoft Excel (.xlsx)
3. Guarda como: precios-backup-20260606.xlsx

PASO 2: INSERTAR FILAS PARA TASAS
───────────────────────────────────────────────────────────────────────────
1. Selecciona Fila 1
2. Clic derecho → Insertar 4 filas encima
3. Ahora tienes filas nuevas 1-4, y datos originales empiezan en fila 5 (antes fila 1)

   ESPERA: Ahora tus datos están en filas 10+, no 6+
   Necesitas moverlos de vuelta:

4. Selecciona datos antiguos (ej: A5:O100)
5. Corta (Ctrl+X)
6. Va a A7 y pega (Ctrl+V)
7. Elimina filas 5-6 vacías

Resultado: Filas 5=Tasas, Fila 6=Headers, Filas 7+=Datos

PASO 3: CREAR TABLA DE TASAS (Fila 5)
───────────────────────────────────────────────────────────────────────────
Usa columnas N-U para las tasas:

N5: 17.0    (COMPRA MEX)      R5: 18.5    (VENTA MEX)
O5: 800     (COMPRA CLP)      S5: 850     (VENTA CLP)
P5: 3800    (COMPRA COP)      T5: 4000    (VENTA COP)
Q5: 25.0    (COMPRA Bs)       U5: 28.0    (VENTA Bs)

Formato recomendado:
  - Fondo: Amarillo (#fbbf24)
  - Texto: Negrita
  - Números: 0-2 decimales según moneda

PASO 4: CREAR COLUMNA "VENTA COP"
───────────────────────────────────────────────────────────────────────────
1. Columna D debe ser "VENTA COP"
2. D7: =C7*$T$5
3. Copia fórmula a D8:D100
4. Valida que resultados sean correctos (ej: 1.66 * 4000 = 6640)

PASO 5: CREAR COLUMNA "COMPRA COP"
───────────────────────────────────────────────────────────────────────────
1. Insertar columna nueva después de E (antes de antigua F)
2. Encabezado: "COMPRA COP"
3. F7: =E7*$P$5
4. Copia a F8:F100

PASO 6: REORGANIZAR RESTO DE COLUMNAS
───────────────────────────────────────────────────────────────────────────
Después de insertar F, ahora tienes:
  C: VENTA USD
  D: VENTA COP
  E: COMPRA USD
  F: COMPRA COP
  G: antiguo "Venta MXN"
  H: antiguo "Venta CLP"
  I: antiguo "Venta Bs"
  ...

Verifica que G, H, I tengan fórmulas:
  G7: =C7*$R$5
  H7: =C7*$S$5
  I7: =C7*$U$5

Y agrega columnas J, K, L para COMPRA (si no existen):
  J7: =E7*$N$5     (COMPRA MXN)
  K7: =E7*$O$5     (COMPRA CLP)
  L7: =E7*$Q$5     (COMPRA BS)

PASO 7: COPIAR FÓRMULAS A TODAS LAS FILAS
───────────────────────────────────────────────────────────────────────────
Para cada columna (D, E, F, G, H, I, J, K, L):
1. Selecciona celda con fórmula (ej: D7)
2. Copia (Ctrl+C)
3. Selecciona rango completo (ej: D8:D100)
4. Pega (Ctrl+V)

PASO 8: VERIFICAR CÁLCULOS

================================================================================
SOLUCIÓN DE PROBLEMAS
================================================================================

Problema: "Error al leer rango A5:L100"
Solución: Verificar que filas 7+ tengan datos (no columnas vacías)
          Si columnas están vacías, Google Sheets no devolverá valores

Problema: "Los precios no cambian cuando cambio tasas"
Solución: Verificar que Google Sheet tiene cache deshabilitado:
          Herramientas → Opciones de cálculo → Recalcular cada minuto

Problema: "La fórmula muestra error #DIV/0!"
Solución: Tasas en N5:U5 están vacías o son texto (no números)
          Escribir número: 17.0 (no "17.0")

Problema: "sheets.js dice 'cannot read property X of undefined'"
Solución: Nueva estructura espera columnas D, E, F (COP). Si no existen,
          actualizar sheets.js a versión anterior o crear las columnas

PREGUNTAS FRECUENTES
================================================================================

P: ¿Puedo cambiar las tasas en tiempo real?
R: Sí, edita N5:U5 cuando quieras. Los precios se actualizan en segundos.

P: ¿Qué pasa si una tasa es 0?
R: sheets.js tiene valores por defecto. Si P5 (COMPRA COP) es 0, usa 3800.

P: ¿Cómo agrego una nueva moneda (ej: EUR)?
R: Inserta columna nueva, agrega tasa en fila 5, agrega fórmula. Muy fácil.

P: ¿Los históricos de ventas se actualizan?
R: No, solo los precios futuros. Los históricos usan tasas del día de venta.

P: ¿Hay limit de filas?
R: No, Google Sheets soporta hasta 10 millones. Nuestro rango es 7-100, 93 filas.

P: ¿Si cambio USD de 1.66 a 1.68, se actualiza COP?
R: Sí si tienes fórmula =E*$T$5. Si es número fijo, no.
