================================================================================

Portal Gamers LATAM utiliza Google Sheets como base de datos central para:
- Gestión de precios dinámicos de todos los juegos
- Registro de compras a proveedores
- Registro de ventas a clientes
- Seguimiento de inventario por servidor
- Intercambios entre servidores

- Node.js (server.js) — API REST que consulta Sheets
- Google Apps Script — Scripts automáticos en el Sheet
- WhatsApp Bot — Registro de pedidos
- Sitio Web — Catálogo dinámico

────────────────────────────────────────────────────────────────────────────
Función: Base maestra de cuentas de juego con stock máximo y alertas
Creación: Automática por inicializarStock() basado en "💰 Precios"
Rango: A1:I100+

Estructura de columnas:

  H = ESTADO (fórmula: =IF(D>0,1,0), muestra "Disponible" o "Sin stock")

  2. Función: inicializarStock()
  3. Lee todas las filas de "💰 Precios" (A6:O30)
  4. Genera fila por servidor con fórmulas automáticas

Ajuste de stock:
  - Venta registrada: D -= cantidad (función _ajustarStockBase)
  - Compra registrada: D += cantidad
  - Saldo negativo: Aviso al usuario

5.3 parseNum(str)
────────────────────────────────────────────────────────────────────────────
Descripción: Convierte números en formato europeo a float JavaScript
Sintaxis: function parseNum(str)
Parámetro: str (string con formato "X.XXX,XX")
Retorna: number (parseado)

Lógica:
  1. Si no existe str o no es string, retorna 0
  2. Elimina todos los puntos: "1.881,60" → "1881,60"
  3. Reemplaza última coma por punto: "1881,60" → "1881.60"
  4. Parsea con parseFloat(), si falla retorna 0

Ejemplos:
  parseNum("1.881,60")  → 1881.60
  parseNum("1,96")      → 1.96
  parseNum("100")       → 100
  parseNum("")          → 0

Usado por: getPricesFromSheet() (cols C, D, E, F, I, O)

5.4 getPricesFromSheet()
────────────────────────────────────────────────────────────────────────────
Descripción: Obtiene catálogo de precios desde "💰 Precios"
Sintaxis: async function getPricesFromSheet()
Parámetros: Ninguno
Retorna: Promise<{Object}>

Estructura de retorno:
{
  'dofus-touch': {
    'BLAIR': {
      venta: 1.66,
      compra: 1.50,
      mxn: 45.60,     // si existe en columna D
      clp: 1490.00,   // si existe en columna E
      cop: 6640,      // si existe en columna I
      ves: 3320       // si existe en columna O
    },
    'TALOK': { venta: 1.54, ... },
    '_meta': {
      min_venta: 1.54,  // precio mínimo entre todos los servidores
      max_venta: 1.66   // precio máximo entre todos los servidores
    }
  },
  'dofus-3': { ... },
  'dofus-retro': { ... },
  'wakfu': { ... },
  'albion': { ... },
  'wow-retail': { ... }
}

Proceso:
  1. Verifica si SHEET_ID existe
  2. Checa caché (TTL=60 segundos)
  3. Si caché válido, retorna caché
  4. Si no, llama sheets.spreadsheets.values.get(SHEET_ID, "💰 Precios!A6:O100")
  5. Procesa cada fila:
     - Identifica juego actual (si col A tiene valor)
     - Mapea nombre con GAME_NAME_MAP
     - Ignora filas que empiezan con "📈" o "MARGEN"
     - Parsea valores numéricos con parseNum()
     - Valida que venta > 0
  6. Lee pestaña WOW_GOLD especialmente (A2:L10)
  7. Calcula _meta (min_venta, max_venta) por juego
  8. Actualiza caché con timestamp actual

Caché:
  - Variable global: let cache = { data: null, ts: 0 }
  - TTL: 60000 ms (60 segundos)
  - Se invalida con: invalidateCache() tras logSale/logOrder

Manejo de errores: Si WOW_GOLD no existe, loga warning pero continúa

Usado por:
  - GET /api/products (server.js) → precios dinámicos del sitio
  - Bot WhatsApp (catalog.js) → catálogo en conversación

5.6 logSale(params)
────────────────────────────────────────────────────────────────────────────
Descripción: Registra una venta en la pestaña "📝 Ventas"
Sintaxis: async function logSale({ juego, servidor, cantidad, precio_m, total_usd, moneda, canal, asesor, pago_id })
Parámetros:
  - juego (string): nombre del juego
  - servidor (string): nombre del servidor
  - cantidad (number): millones vendidos
  - precio_m (number): precio por millón en USD
  - total_usd (number): monto total en USD
  - moneda (string, opcional): tipo de moneda (default: observado de datos)
  - canal (string, opcional): fuente (default: "Web")
  - asesor (string, opcional): vendedor (default: "Sistema")
  - pago_id (string, opcional): ID de pago externo

Retorna: Promise<void>

Proceso:
  1. Si SHEET_ID no existe, retorna (no hace nada)
  2. Obtiene timestamp actual en zona Colombia (America/Bogota)
  3. Formatea total_usd como "$X.XX"
  4. Llama sheets.spreadsheets.values.append() al rango "📝 Ventas!A:J"
  5. Append una sola fila con 10 columnas:
     [FECHA, ASESOR, CANAL, JUEGO, SERVIDOR, CANTIDAD, MONEDA, PRECIO_M, TOTAL, TOTAL]
  6. Invalida caché de precios
  7. Retorna (sin esperar respuesta del servidor remoto)

Valores por defecto:
  - asesor: "Sistema"

────────────────────────────────────────────────────────────────────────────
Descripción: Obtiene todas las reseñas de clientes desde "RESEÑAS"

Descripción: Calcula el total de ventas del día actual en USD

11. SEGURIDAD Y NOTAS OPERACIONALES
════════════════════════════════════════════════════════════════════════════

11.1 Credenciales
────────────────────────────────────────────────────────────────────────────
- Archivo sheets-key.json contiene privada key (MANTENER PRIVADO)
- NO pushearlo a GitHub (está en .gitignore)
- En producción (Railway), usar variable GOOGLE_CREDENTIALS (JSON en env)
- Service Account tiene solo permisos de lectura/escritura en Sheets (no Drive)

11.2 Caché
────────────────────────────────────────────────────────────────────────────
- getPricesFromSheet() cachea 60 segundos
- getResenas() cachea 60 segundos
- invalidateCache() se llama tras venta para actualizar inmediatamente
- Si Sheets no responde en 5 segundos, fallback a products.json local

11.3 Timezone
────────────────────────────────────────────────────────────────────────────
- Todas las fechas se graban en zona: America/Bogota (Colombia)
- Importante para reporte diario: getDailySalesStats() compara con "hoy" en Colombia

11.4 Validación
────────────────────────────────────────────────────────────────────────────
- parseNum() maneja formato europeo (1.881,60)
- Validación de campos obligatorios en Google Apps Script
- Lookup de servidor → juego (getJuegoPorServidor)
- No hay validación de duplicados

11.5 Limitaciones conocidas
────────────────────────────────────────────────────────────────────────────
- Max 2,000 filas por pestaña (rangos A4:I2000)
- No hay sincronización bidireccional (solo Sheet → API)
- Edición simultánea en Google Sheet puede causar race conditions
- Google Sheets API tiene quota diaria (10,000 solicitudes)

11.6 Mantenimiento
────────────────────────────────────────────────────────────────────────────
- Actualizar SHEET_ID en .env si se cambia de Sheet
- Revisar "💰 Precios" regularmente (precios pueden desactualizar)
- Limpiar filas antiguas en "📝 Ventas" anualmente (archive histórico)
- Verificar "Stock Y Cuentas Base" para detectar stock bajo
